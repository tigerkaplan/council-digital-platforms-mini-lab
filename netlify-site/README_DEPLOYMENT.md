# Static case-study package

This package is a static presentation of the Council Digital Platforms Mini Lab case study. It is prepared for deployment review only and is not a live Drupal application or a live council service.

`index.html` is the site entry point. `assets/` contains the static stylesheet and navigation script. `evidence/` contains only the approved evidence files linked by the case study. `selected-public-evidence/` records the selection and safety boundary for that compatibility path.

The GitHub action is intentionally unavailable until a clean public repository and its URL have been independently verified. No Live action is included because no deployment URL exists.

Do not deploy this package before independent review and the release checklist are complete.
