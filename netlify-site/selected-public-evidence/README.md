# Selected public evidence

The package stores selected evidence at `../evidence/` so the accepted case-study document can retain its tested relative links. This directory records that the compatibility path contains only files selected from the accepted clean release candidate.

The selection contains public fictional form, workflow, confirmation, technical-evidence and bounded Mendix material. The Mendix selection contains only the public-safe derivatives and selected fictional local-runtime views. Original Studio Pro views, source packages, private records and databases are not included.
